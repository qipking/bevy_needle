# CJK 字体（不随仓库分发，31MB）

demo 界面含中文文案，需要 Noto Sans Mono CJK。任选其一：

```bash
# Fedora 系统包自带，直接复制：
cp /usr/share/fonts/google-noto-sans-mono-cjk-vf-fonts/NotoSansMonoCJK-VF.ttc .

# 或从 Google Fonts 下载（任一 CJK 字体改名为同路径亦可）：
# https://github.com/notofonts/noto-cjk/releases
```

没有字体时 demo 仍可运行，但中文显示为缺字方块（英文正常）。
